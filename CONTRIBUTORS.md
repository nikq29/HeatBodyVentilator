## 🤝 Wie man beiträgt

Wir freuen uns über Beiträge! So kannst du helfen:

1. **Issues melden**: Bugs, Feature-Requests oder Verbesserungsvorschläge
2. **Pull Requests**: Code-Verbesserungen, neue Features, Bugfixes
3. **Dokumentation**: Verbesserungen an README, Kommentaren, Anleitungen
4. **Testing**: Testen auf verschiedenen Hardware-Plattformen

### Contribution Guidelines

- 📝 Beschreibe deine Änderungen klar in Pull Requests
- ✅ Teste deinen Code vor dem Einreichen
- 📚 Aktualisiere die Dokumentation bei Bedarf
- 🔍 Halte dich an den bestehenden Code-Stil

### Lizenz-Hinweis für Contributors

Mit deinem Beitrag:
- Bestätigst du, dass du die Rechte an deinem Code besitzt
- Lizenzierst du deinen Beitrag unter der Projekt-Lizenz
- Behältst du dein Urheberrecht an deinem ursprünglichen Beitrag
- Wirst du hier als Contributor aufgeführt

Siehe [LICENSE](LICENSE) für Details.
